# Telegram-бот расписания

Бот читает XLSX-файлы из папки Google Drive и её вложенных папок, сохраняет
расписание в SQLite и проверяет папку каждые пять минут. Для новых или
изменённых пар он отправляет сообщения подписчикам соответствующей группы.
При первом запуске текущее содержимое загружается без рассылки старых пар.

Парсер рассчитан на проверенный формат файлов в указанной папке: листы
«Пара 1»–«Пара 7», по два блока строк на листе, каждый блок содержит
кабинет, группу и преподавателя. Дата берётся из имени файла, например
`06.10.2026.xlsx`.

## Подготовка

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и скопируйте
   токен.
2. В Google Cloud включите Google Drive API, создайте сервисный аккаунт и
   скачайте его JSON-ключ. Не добавляйте ключ в Git.
3. Предоставьте сервисному аккаунту доступ к папке Google Drive (и вложенным
   папкам), скопировав его адрес из `client_email` в JSON-ключе.
4. Установите Python 3.10 или новее и зависимости:

   ```sh
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

5. Скопируйте `.env.example` в `.env` и укажите токен и путь к ключу:

   ```env
   BOT_TOKEN=токен_от_BotFather
   GOOGLE_SERVICE_ACCOUNT_FILE=./service-account.json
   ```

   Идентификатор Drive-папки уже заполнен. По необходимости можно изменить
   `DRIVE_FOLDER_ID`, `DATABASE_PATH` и интервал `POLL_INTERVAL_SECONDS`
   (минимум 30 секунд).

6. Запустите:

   ```sh
   python main.py
   ```

## Команды бота

- `/groups` — группы в доступном расписании.
- `/subscribe СА-15` — подписаться на группу.
- `/unsubscribe СА-15` — отменить подписку.
- `/mygroups` — показать свои подписки.
- `/schedule СА-15` — показать пары группы на ближайшие семь дней.
- `/schedule` — показать расписание по своим подпискам.

Бот использует long polling для Telegram, поэтому отдельный публичный сервер
для webhook не требуется. Для непрерывной работы процесс нужно разместить на
сервере или компьютере, который не выключается.
